# CoPaw 智能体记忆功能 — 对话测试用例

> **使用方式**：启动 CoPaw 后，按下面的用例逐条跟智能体对话，检查它的回答是否符合预期。
> 每个用例包含：你说的话 → 智能体应该怎样回应 → 你怎么判断通过/失败。

---

## 一、记忆写入（让智能体记住东西）

### TC-01 记住个人信息

| 步骤 | 你说的话 | 期望行为 |
|------|---------|---------|
| 1 | `请记住，我叫张三` | 智能体确认记住了你的名字 |
| 2 | `我叫什么名字？` | 回答"张三" |

**通过标准**：能准确回忆起名字
**验证文件**：检查 `~/.copaw/MEMORY.md` 或 `~/.copaw/memory/` 下是否有相关记录

---

### TC-02 记住多个偏好

| 步骤 | 你说的话 | 期望行为 |
|------|---------|---------|
| 1 | `我喜欢用 Python 写代码，编辑器用 VS Code，操作系统是 Windows` | 确认记住三条偏好 |
| 2 | `我喜欢用什么编程语言？` | 回答 Python |
| 3 | `我用什么编辑器？` | 回答 VS Code |
| 4 | `我用的什么操作系统？` | 回答 Windows |

**通过标准**：三条偏好都能分别准确回忆

---

### TC-03 记住具体事件

| 步骤 | 你说的话 | 期望行为 |
|------|---------|---------|
| 1 | `今天（2026-07-12）我把项目部署到了服务器上，用的 Docker` | 确认记住 |
| 2 | `我什么时候部署的项目？` | 提到 2026-07-12 |
| 3 | `我用什么部署的？` | 提到 Docker |

**通过标准**：事件的时间和方式都能回忆

---

### TC-04 记住数字和量化信息

| 步骤 | 你说的话 | 期望行为 |
|------|---------|---------|
| 1 | `我的服务器有 3 台，分别在北京、上海、广州` | 确认记住 |
| 2 | `我有几台服务器？` | 回答 3 台 |
| 3 | `都在哪些城市？` | 回答北京、上海、广州 |

**通过标准**：数字和地点都准确

---

### TC-05 更新已有记忆

| 步骤 | 你说的话 | 期望行为 |
|------|---------|---------|
| 1 | `请记住我的邮箱是 old@example.com` | 确认记住 |
| 2 | `我的邮箱改成了 new@example.com，帮我更新一下` | 确认更新 |
| 3 | `我的邮箱是什么？` | 回答 new@example.com（不是旧的） |

**通过标准**：记忆被正确更新，不会返回旧值

## 二、记忆检索（问智能体之前的事）

### TC-06 直接回忆

| 前置 | 先完成 TC-01 步骤 1 |
|------|---------------------|
| 测试 | `你还记得我叫什么吗？` |
| 期望 | 回答你的名字 |

---

### TC-07 语义回忆（换个问法）

| 前置 | 先完成 TC-02 步骤 1（记住偏好 Python + VS Code + Windows） |
|------|----------------------------------------------------------|
| 测试 | `我平时开发用什么工具？` |
| 期望 | 能关联到 VS Code 和 Python，而不是答非所问 |

**通过标准**：换一种说法也能检索到对应记忆

---

### TC-08 回忆不存在的记忆

| 测试 | `你还记得我喜欢的颜色吗？`（之前从未提过） |
|------|------------------------------------------|
| 期望 | 诚实说"没有记录"或"你还没告诉过我"，而不是瞎编 |

**通过标准**：不编造不存在的记忆

---

### TC-09 跨天记忆持久化

| 步骤 | 操作 |
|------|------|
| 1 | 今天对话中告诉智能体一个信息 |
| 2 | **关闭 CoPaw，重启服务** |
| 3 | 重新对话，问 `你还记得我昨天告诉你的 XX 吗？` |
| 期望 | 能回忆起来（记忆持久化到了文件） |

**通过标准**：重启后记忆不丢失

## 三、上下文压缩（长对话记忆）

### TC-10 手动触发压缩

| 步骤 | 操作 |
|------|------|
| 1 | 先聊几轮有实质内容的对话（比如告诉智能体你的项目信息） |
| 2 | 输入 `/compact` |
| 3 | 观察返回信息，确认显示 "Compact Complete" 和压缩摘要 |
| 4 | 问 `你还记得我的项目信息吗？` |
| 期望 | 压缩后仍能回忆关键信息 |

**通过标准**：
- `/compact` 命令正常返回
- 摘要中包含关键信息
- 压缩后还能回答问题

---

### TC-11 自动压缩触发

| 步骤 | 操作 |
|------|------|
| 1 | 连续发送大量消息（20-30 轮以上），每轮都包含不同信息 |
| 2 | 观察智能体是否自动触发压缩（日志中会看到 "Marked X messages as compacted"） |
| 3 | 问最后几轮提到的内容 |
| 期望 | 最近的消息仍然记得（未被压缩掉） |

**通过标准**：
- 自动压缩在上下文过长时触发
- 最近 3 条消息（`MEMORY_COMPACT_KEEP_RECENT`）保留
- 不丢失最近对话

---

### TC-12 压缩后关键信息保留

| 步骤 | 操作 |
|------|------|
| 1 | 告诉智能体：`我的数据库密码是 abc123，服务器 IP 是 10.0.0.1` |
| 2 | 再聊几轮其他话题 |
| 3 | 输入 `/compact` |
| 4 | 问 `我的服务器 IP 是什么？` |
| 期望 | 能回忆起 IP 地址 |

**通过标准**：压缩摘要中保留了关键数据

## 四、记忆搜索工具

### TC-13 触发 memory_search

| 步骤 | 你说的话 | 期望行为 |
|------|---------|---------|
| 1 | 先写入几条记忆（不同主题） | — |
| 2 | `帮我搜索一下我之前关于数据库的记录` | 智能体调用 memory_search 工具，返回相关片段 |

**通过标准**：
- 智能体主动调用 memory_search 工具
- 返回结果包含文件路径和行号
- 内容与查询相关

|------|------------------------------------------------|

## 六、综合场景测试

### TC-17 完整工作流

按顺序执行以下完整流程：

```
第 1 轮：「我叫小明，是一名后端工程师，主要用 Go 和 Python」
         → 智能体确认

第 2 轮：「我的项目在 GitHub 上，仓库叫 my-awesome-api」
         → 智能体确认

第 3 轮：「帮我记住，部署用 Docker Compose，数据库用 PostgreSQL」
         → 智能体确认

第 4 轮：「我叫什么？做什么的？」
         → 应回答：小明，后端工程师

第 5 轮：「我的项目叫什么？用什么数据库？」
         → 应回答：my-awesome-api，PostgreSQL

第 6 轮：/compact
         → 压缩成功

第 7 轮：「我是谁？项目用的什么技术栈？」
         → 压缩后仍能回答出关键信息
```

**通过标准**：全流程 7 轮都符合预期

---

### TC-18 记忆更新 + 搜索

```
第 1 轮：「我的部署环境是 staging」
第 2 轮：「改一下，部署环境改成 production 了」
第 3 轮：「搜索一下我的部署环境」
         → 应返回 production（不是 staging）
```

## 八、测试前准备

```bash
# 1. 启动 CoPaw
copaw start

# 2. 清空之前的记忆（可选，确保干净的测试环境）
#    删除 ~/.copaw/MEMORY.md 和 ~/.copaw/memory/ 下的文件

# 3. 确认记忆管理器已启用
#    环境变量 ENABLE_MEMORY_MANAGER 不要设为 false

# 4. 如需测试语义搜索，确保 embedding 已配置
#    set EMBEDDING_API_KEY=你的key
#    set EMBEDDING_MODEL_NAME=text-embedding-v3
```
