---
name: CoPaw Memory Evaluation Style
description: User prefers concise Chinese troubleshooting with exact commands, concrete file paths, and the reason each command matters.
type: feedback
---

**Rule:** When helping with CoPaw memory evaluation issues, answer in Chinese and include exact paths, exact commands, and the reason for each command.

**Why:** The user is actively comparing memory strategies and debugging the frontend evaluation workflow, so abstract advice is less useful than reproducible steps.

**How to apply:** For memory eval, console, backend, or suite questions, lead with the likely cause, then give the shortest command path to confirm it.
